# Node.js Fundamentals

A dependency-free HTTP API used to study Node.js streams, routing and low-level request handling.

## Project goal

Understand what frameworks abstract by implementing API behavior directly with Node.js core modules.

## Features

- HTTP server without a framework
- In-memory or file-backed data handling
- Request-body parsing with streams
- Route matching

## Technologies

- **JavaScript**
- **Node.js**
- **Node.js Streams**

## What I learned

- Creating an HTTP server with core Node.js APIs
- Reading and transforming request streams
- Implementing basic routing manually
- Understanding the foundation beneath web frameworks

## Running locally

```bash
npm install
npm run dev
```

## Project status

This is a learning project and is not presented as a production-ready application.
